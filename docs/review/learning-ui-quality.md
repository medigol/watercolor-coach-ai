## Implemented changes

- **Hands-on studio:** lesson/project title, step and practical actions come first. Observation cue, real checklist and completion controls follow. On mobile, the visual/theory is opened beside the observation cue; on desktop it occupies the right-hand studio column. Notes, materials, exercise plan and optional media use disclosure. The outline, previous step, pause/path and existing completion/reflection rules remain available. No timer, automatic completion or new save contract.
- **Navigation:** a single 44px contextual row replaces the repeated five-button mobile navigation. Menu includes path, curriculum, styles, progress, preferences and resume. Learn uses a full-width top application navigation at ≥1000px; other app workflows retain their existing navigation. No fixed lesson action overlays. Footer space and wrapping keep final controls reachable.
- **Visual system:** reusable studio tokens, restrained serif headings, readable body type, quieter surfaces, consistent selection ticks and focus treatment. First visit prioritises two starting modes. Returning view shows the next actual action. Path becomes an ordered sequence with reasons and prerequisite details; curriculum distinguishes foundations, applications and outlines; progress foregrounds activity and reflection.
- **Style Explorer:** four larger, original digital illustrations, distinct observed features, concise primary/secondary controls and a two-example visual comparison. Atmospheric, urban and expressive illustrations share a cottage/landscape motif; botanical uses a flowering branch. These demonstrate visual choices, **not authentic physical pigment behaviour**.
- **Teaching diagrams:** irregular concentration/load comparisons; scene-to-three-value simplification; different hard/soft/lost boundaries; geometrically consistent two-point construction. Captions and accessible descriptions identify these as explanatory illustrations.

No curriculum, lesson text/data, skill graph, engine, learning provider, storage keys/schema, dependencies, backend, auth, quotas or production source lock was changed. Four lessons, eight project steps, prior completion, checklists, reflections and notes are retained.
