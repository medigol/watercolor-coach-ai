## Sixteen-dimension human rubric

Record **supported / uncertain / unsupported / not applicable**, quote the exact output and point to the independently identified source region. Use at least two independent blind reviewers for a comparative quality claim. Preserve disagreements. A schema-valid response receives no automatic artistic pass.

| Dimension | Pass criterion | Failure criterion |
|---|---|---|
| 1 Image fidelity | Named relationships are visible in exact analysed selection | Description belongs to surrounding UI or another image |
| 2 Major subjects | Correct identities and coarse locations | Invented/misidentified major object |
| 3 Focal hierarchy | Attention reading supported by several visible relationships, qualified as interpretation | Hue alone claimed strongest tonal contrast or arbitrary focal object |
| 4 Composition | Supplied structure corresponds to masses/anchors; archetype-specific teaching | Stock formula, fabricated path or mismatched landing |
| 5 Colour terminology | Hue/temperature/chroma used distinctly and plausibly | Unsupported formal complementary/pigment identity claim |
| 6 Colour versus value | Tonal claims checked independently against original/grayscale | Hue contrast treated as grayscale separation |
| 7 Watercolour pedagogy | Suggested methods are workable, qualified experiments | Implausible mix, unsafe repainting of unknown finished art |
| 8 Process honesty | Visible effect separated from suggested future technique | Definite original glazing/lifting/pigment/brush sequence |
| 9 Calibration | Rationale and surviving material issues agree without forced praise/defects | Unqualified excellent/no-issue verdict despite contradictory serious evidence |
| 10 Specificity | What/where/why and intended effect are identifiable | Generic improve-contrast/composition filler |
| 11 Educational usefulness | Explains a transferable relationship worth preserving/testing | Description/praise with no useful artistic reasoning |
| 12 Practice relevance | One supplied variable, constants, comparison/success cue; separate paper | Unrelated hidden flaw or several variables disguised as one |
| 13 Annotation accuracy | Actual crop/guide lies in independently accepted region | UI, unrelated object, wrong source or endpoint |
| 14 Internal consistency | Overall/strengths/recommendations/colour/technique/practice agree | One section preserves what another arbitrarily corrects |
| 15 Clarity/economy | Complete distinct sentences, working evidence controls | Corrupt fragments, HTML entities, repetitive cards |
| 16 Stylistic respect | Intent/alternatives distinguished from demonstrable inconsistency | Automatic realism/thirds/high-detail/high-contrast preference |

|---|---|---|
| Exact three originals/outputs absent | Cannot validate subject/medium/localization or claim better artistic critique | Must complete exact-case review before unconditional READY/freeze |
