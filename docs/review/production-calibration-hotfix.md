# Production calibration and reliability hotfix

Branch: `codex/production-calibration-hotfix`. Baseline: `d9b7b5044653874410e79f6303607aea7ba129be` (production main after PR #24). No branch/PR creation or merge was performed remotely.

This patch addresses the reported live 422 failures through **both safe metadata/reference repair and prompt consistency improvements**. It does not establish that intermittent live failures are fully resolved; confirmation requires deployment and new live painting tests. No captured live provider response or evidence of actual output truncation was available. The existing synthetic truncation test still rejects incomplete output instead of increasing the token cap.

## Reliability

- A misplaced insight domain is normalized only when exactly one supplied expert view references it and every referenced supplied fact supports that view's domain. Lesson/action text stays unchanged. Views are then rebuilt from their supplied references.
- Same normalized area + same semantic role + distinct role IDs can merge. Valid region wins before confidence; otherwise higher valid confidence wins. Equally reliable differing geometry remains fatal. Equal geometry/metadata may use a stable lexical ID tiebreaker.
- Facts, visual evidence and optional colour role references are remapped to the retained supplied role ID. No role judgement, fact, recommendation, prose or geometry is generated by structural repair.
- Missing required material, unusable required text, unknown/ambiguous identities, unresolved required domain ownership, same-area conflicting roles and ambiguous focal identities still fail. Malformed optional evidence, colours, regions, secondary composition and brush aids are independently dropped.
- Private fixed diagnostics now distinguish `view_domain_mismatch` and `conflicting_roles`, alongside existing view-reference, missing-domain, core-text and required-structure codes. The handler logs no model prose, user identifiers, images or credentials.

## Coaching calibration

- Competent/developing work is prompted to identify meaningful evidence-supported next-level priorities; when only strengths/subtle refinements are justified, reconsider Strong. The frontend does not invent criticism or reassign quality levels by counting recommendations.
- Supplied integration/grouping/compression guidance is eligible for elevation. Located visual relationships rank above generic contrast/formula advice, with issue/evidence priority retained within each specificity tier. Competent/developing recommendations remain capped at three; highly resolved remains capped at two and can have zero. Strong can have zero clear issues.
- Central placement is not itself a defect. Unsupported relocation is a stylistic study alternative. Unrelated background competition cannot establish positional harm; concrete supplied positional evidence and harm are required.
- What works suppresses exercise actions. An imperative strength lesson uses its supplied factual observation instead. Suitable controlled exercises may be owned by Practice.
- Quality rationale omits trailing optional-criticism sentences while retaining positive evidence. Separate-study framing is normalized once without changing the study variable.

## Evidence and colour/process safety

- Each confidently located colour renders its own `colourEvidence(...)` plan directly, outside the general evidence allocator. Shared source geometry no longer inherits a different colour's label. Role fallback captions also use the requested colour label.
- Missing evidence reads: “No confidently located source detail for this colour.” The wording applies to new and saved results.
- Temporary crop context has minimum normalized width/height (0.18/0.16), bounded aspect-aware expansion, and existing adaptive margins/clamping. The canonical target is projected unchanged inside the display crop. Original signed URI only; no files, uploads, database writes or model calls.
- Process assertions matching the reported wash/application/layering phrases become observable overlapping-colour/soft-transition wording. Unsupported unreconstructable history is still omitted; visible horizontal layering of bands and suggested wet-on-wet practice remain allowed.
- An optional recreation mix containing white/PW4/PW6 is dropped unless an opaque/gouache variation is explicit. Dropping the entire mix preserves formula/ratio honesty and invents no replacement pigment. Approximate 1:1/2:1/3:1 and existing complementary/pigment-identity safeguards remain.
